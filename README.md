# Laboratorio ADK - UCV

Repositorio oficial del laboratorio de desarrollo de agentes con **Google Agent Development Kit (ADK)**, Python, Poetry, y pruebas unitarias integradas con CI/CD en GitHub Actions.

##  Requisitos y Tecnologías
- Python 3.10+
- Poetry (Gestor de dependencias)
- Google ADK (`gemini-3.8-flash`)
- Unittest / Pytest

##  Instalación y Configuración local

1. Clonar el repositorio e ingresar a la carpeta:
   ```bash
   git clone [https://github.com/danielaaaq2/laboratorio-adk-ucv.git](https://github.com/danielaaaq2/laboratorio-adk-ucv.git)
   cd laboratorio-adk-ucv
